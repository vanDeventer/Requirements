# docs: the vocabulary and design

[requirements-model.md](requirements-model.md) explains the terms (idea,
need, goal, requirement, specification, …), how they relate, the data model
the Go code implements, how it maps to Turtle and SysML v2, and the
standards it draws on.

`figures/` holds its two diagrams: the relations between the terms and the
data model. They are hand-written SVG, so they can be edited as text when the model changes.
